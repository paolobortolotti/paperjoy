Una skill gratuita per Claude Code. Come installarla · Cosa c'è dentro

Funziona per luoghi e storie: città, borghi, hotel, eventi. Non per oggetti con un interno da spiegare, come un motore: lì il pop-up non mostra niente.

Esempi

Ogni libro viene dalla richiesta scritta sotto, sullo stesso motore: cambia solo la descrizione della scena. Qui si sfogliano da soli; a tutta pagina si tirano le linguette, si alzano gli sportelli e si girano le ruote.

La tua città

Le otto città sono esempi. Per un altro luogo si cambia la descrizione, non il codice.

  1. Descrivi il luogo

    Cosa si alza dalla pagina e cosa si può toccare. Due righe bastano.

  2. Il controllo delle pieghe

    Prima della consegna un validatore apre e chiude il libro e prova ogni piega come su carta vera. Se un pezzo sporge o ne urta un altro, dice quale e di quanti millimetri.

  3. Un solo file

    Un HTML tra 160 e 270 KB, senza dipendenze: si apre nel browser o si incolla in una pagina del sito.

Cosa si muove

Sei meccanismi presi dai libri pop-up veri. Ogni pezzo è incollato e piegato come in carta: nessuno galleggia.

Facciate

Una piega parallela alla costola: palazzi, ponti, file di case.

Gradoni

Pieghe annidate che scendono verso chi legge: terrazze, scalinate.

Torri

Una piega a V sulla costola: campanili, fari, la Mole.

Linguetta

Si tira dal bordo e qualcosa attraversa la pagina: una nave, un bus, un treno.

Sportello

Si alza e mostra cosa c'è sotto o dentro: un cortile, la metro, un caffè.

Ruota

Si gira e cambia la scena: l'ora, la stagione, il giorno e la notte.

Installa

Tre passi, un paio di minuti. Servono Claude Code e Node.js: node -v nel Terminale ti dice se c'è.

  1. Installa

    Apri il Terminale (su Mac: ⌘ Spazio, scrivi Terminale), incolla questa riga e premi Invio.

    git clone https://github.com/paolobortolotti/popup-carta ~/.claude/skills/popup-carta
  2. Riavvia Claude Code

    Chiudilo e riaprilo: legge le skill all'avvio.

  3. Chiedi un libro

    Descrivi il luogo a parole, oppure comincia con /popup-carta. Claude salva un file .html nella cartella in cui lavori: aprilo con un doppio clic.

  1. Scarica

    popup-carta-main.zip da GitHub.

  2. Apri lo zip

    Doppio clic nella cartella Download: esce la cartella popup-carta-main. Leggi pure SKILL.md: sono le istruzioni che segue Claude.

  3. Spostala tra le skill

    Nel Terminale incolla questa riga, poi riavvia Claude Code.

    mkdir -p ~/.claude/skills && mv ~/Downloads/popup-carta-main ~/.claude/skills/popup-carta

Testo in chiaro

Le istruzioni per Claude, il motore in JavaScript, lo schema della scena, i libri d'esempio e due font. Nessun file eseguibile già compilato.

All'installazione non parte niente

Si copiano dei file in una cartella. Nessuno script, nessun pacchetto da scaricare, nessuna dipendenza.

Il libro resta nel browser

Ogni libro è un file HTML con motore e font dentro. Non fa richieste esterne, non traccia e non chiede account.

Domande

Cos'è una skill?

Una cartella di istruzioni e file che Claude legge quando il compito la riguarda. Questa gli insegna a scrivere la scena del libro in un JSON e a farla controllare dal motore prima di consegnarla.

Claude non la usa

Controlla che esista ~/.claude/skills/popup-carta/SKILL.md e riavvia Claude Code. Puoi anche chiamarla per nome con /popup-carta.

Funziona su claude.ai?

Non l'ho provata lì. Il controllo delle pieghe gira con Node.js, quindi l'ambiente sicuro è Claude Code sul tuo computer.

Posso metterlo in una pagina del mio sito?

Sì. Chiedi il libro «da incollare in una pagina»: invece del file intero ricevi il blocco con stile, libro e script, che prende la larghezza del contenitore.

Come la aggiorno o la tolgo?

Per aggiornarla: git -C ~/.claude/skills/popup-carta pull. Per toglierla basta cancellare la cartella ~/.claude/skills/popup-carta.

Posso usarla per lavori commerciali?

Sì. Il codice ha licenza MIT; i font Bebas Neue e DM Sans hanno licenza SIL Open Font License. I libri che crei sono tuoi.
